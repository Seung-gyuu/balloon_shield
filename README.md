# balloon_shield

## Game Description
"The game ends when the square touches the balloon! The goal is to survive as long as possible."

In this game, you control a square using the mouse and must avoid touching the balloons. <br/>
The objective is to survive as long as you can without colliding. As the game progresses, it gets harder, and beating your best score is the ultimate challenge.

## 🎮 Game Features
- Control the square using the mouse.
- Avoid touching the balloons to survive.
- Track your best score and try to beat it.
- Enjoy smooth animation transitions that enhance gameplay.

## 🛠️ Tech Stack
- **Game Engine**: Unity
- **Control Method**: Mouse
- **Programming Language**: C#
- **IDE**: Visual Studio
